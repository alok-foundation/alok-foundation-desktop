Set up the admin login

Do this once. It lets the website's “Admin login” save changes into this GitHub repository.

Create it on github.com → Settings → Developer settings → Fine-grained tokens, for this repository only, with “Contents: Read and write”.
Advanced

🔒 The access key is stored in the repository encrypted with the admin username + password (AES-256, 600,000 PBKDF2 rounds). Anyone can download the encrypted file, so a long password matters: a short or common one can be guessed by trying many passwords offline. To change the password later, just run this setup again.
